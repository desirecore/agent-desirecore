## L0

巡检前端项目看"页面数/文件类型"而非代码行数；截图检空白/重复要用体积+md5 双指标。

## L1

### 教训 1：代码行数会掩盖"零 UI 产出"
mock/类型/工具层的行数增长 ≠ 产品进度。多 Agent 前端项目巡检必须单列 UI 产物：
`find src -name "*.tsx" | wc -l` 与页面目录存在性（`ls -d src/pages src/views src/components src/app`），
不能只看 `.ts`+`.tsx` 合计行数。

### 教训 2：截图质检三步（缺一会漏判）
1. **体积分布**（`stat -f "%z %N"`）：只出现 1~2 种数值 = 废片。统一体积的空白/登录页是
   "认证注入失效"的稳定特征；file:// 直开 dist 整批同尺寸空白也是典型（静态资源路径解析不到）。
2. **md5 去重**：同 hash 多张 = 重复采集。判重复只能按 md5 分组，不能按文件数或体积种类推断。
3. **按来源分桶**：按文件名前缀/采集方式拆开，同一页面被多种方式重复截会稀释问题信号。
